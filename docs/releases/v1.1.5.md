## 日本語

### 修正：レースクロックを有効にするとラップタイム・ベストラップが消える

レースクロックを表示すると、クロックは出るもののラップタイム・ベストラップ・順位が表示されなくなっていました。

**原因**はゴーグル側の表示の仕組みです。ゴーグルは画面を保持せず、DISPLAY のたびに「直前の DISPLAY 以降に書かれた行」だけを表示します。プラグインは各処理が自分の行だけを書いて DISPLAY していたため、**毎秒更新されるレースクロックが、そのたびに画面をクロックだけに置き換えていました**。

**修正**として、プラグインがゴーグルごとに「今表示すべき画面」を保持し、DISPLAY のたびに **全消去 → 全行 → 表示** の1フレームをまとめて送るようにしました。

- 画面を保持するゴーグル・しないゴーグルのどちらでも正しく表示されます
- 1行が欠落しても、次の秒のクロック更新で自動的に復旧します

### 修正：完走後に順位行が再表示される

完走時に順位行を消して結果を表示したあと、ラップタイムの再描画（v1.1.4 で追加）によって `POSN: n | LAP: n` が再び表示されていました。完走後は順位行を再描画しないようにしました。

### 変更：初期値を実際のレース運用に合わせました

新規インストール時に、設定を入力しなくてもそのまま使えるようにしました。

**一般設定**

| 項目 | 初期値 |
|---|---|
| バックパック接続タイプ | **SOCKET** |
| レースディレクター バインドフレーズ | **yanazoo** |

**OSD 設定**

| 項目 | 初期値 |
|---|---|
| ベストラップを常に表示 | **有り** |
| 現在の順位とラップを表示 | **有り** |
| レースクロックを表示 | **有り** |
| レース後の結果を表示 | **有り** |
| 各メッセージ | `w ARM NOW x` などシンボル付き |
| 終了メッセージ表示時間 | **100**（10秒） |
| ラップ結果表示時間 | **50**（5秒） |

**表示位置**（初期設定で表示する要素が同じ行に重ならない配置）

| 行 | 内容 |
|---|---|
| 1 | 現在の順位とラップ |
| 2 | レースクロック |
| 5 | レースステータス |
| 8 | ラップタイム（行15から移動） |
| 10–11 | レース後の結果 |
| 12 | ベストラップ |

ラップタイムを行15から行8に移したため、行数の少ないアナログ（NTSC 13行）のゴーグルでも画面外になりません。

> ⚠️ RotorHazard では、**保存済みの設定は初期値で上書きされません**。既にお使いの環境では、アップデート後に設定画面を確認し、必要に応じて手動で変更してください。

### 改善：インストーラがインストール先を自動検出

NuclearHazard 4.4.0 ではユーザー名が `NuclearHazard` から `nuclear` に変わったため、旧インストーラは「インストール先が見つかりません」で失敗していました。

インストール先のパスを固定せず、**RotorHazard のサービス設定から本体の場所を特定**するようにしたため、ユーザー名やディレクトリ構成が違う環境でもインストールできます。

- ダウンロードしたファイルを検証してから入れ替えるため、**途中で失敗しても動作中のプラグインは壊れません**
- 旧版を `.vrxc_elrs-backup/` に直近3世代まで退避します
- 再起動後、プラグインが読み込まれたかをログで自動確認します
- `--dry-run`（設置先の確認のみ）、`--ref=v1.1.5`（バージョン指定）、`--dir=PATH`（設置先の指定）に対応

### ⚠️ ファームウェアの再書き込みは不要です

本リリースは RotorHazard プラグイン側だけの変更です。**ELRS Netpack（XIAO / Wrover）は v2.4 のまま**お使いいただけます。

### インストール・アップデート

```bash

```

このバージョンを指定して入れる場合:


- NuclearHazard 4.4.0（Raspberry Pi 5）の実機で、インストーラによる導入と、順位・レースクロック・ラップタイム・ベストラップの同時表示を確認しました
- レース一巡（ステージ→スタート→ラップ→完走→停止）のシミュレーションを、画面を保持するゴーグルと保持しないゴーグルの2通りで実施し、修正前はご報告の症状を再現、修正後はどちらでも全要素が表示されることを確認しました
- 初期値40項目を指定の設定表と自動で照合し、全項目一致を確認しました

## English

### Fixed: enabling the race clock made the lap time and best lap disappear

With the race clock on, the clock showed but the lap time, best lap and position vanished.

The goggles don't keep a persistent canvas: each DISPLAY shows only the rows written since the previous DISPLAY. Each handler wrote just its own rows and displayed, so the **race clock, redrawing every second, replaced the screen with only the clock on every tick**.

The plugin now keeps the intended screen for each recipient and every DISPLAY sends a complete frame — **clear, every row, display**. This is correct whether or not the goggles keep their canvas, and a lost row heals on the next clock tick.

### Fixed: position row reappearing after a pilot finishes

After the finish screen cleared the position row, the lap-time redraws added in v1.1.4 wrote `POSN: n | LAP: n` back. Redraws now skip the position row once the pilot is done.

### Changed: defaults now match race-day use

A fresh install works without configuring the panels: SOCKET connection, race-director bind phrase set, best lap / position / race clock / post-race results on, symbol-decorated messages (`w ARM NOW x` etc.), 10 s finish message, 5 s lap results.

Rows are laid out so the enabled elements never overlap — position 1, clock 2, status 5, lap time 8 (moved from 15, which is off-screen on a 13-row NTSC analog OSD), results 10–11, best lap 12.

> ⚠️ RotorHazard does not overwrite saved settings with new defaults. On an existing install, check the settings pages after updating.

### Improved: installer finds the plugin directory itself

NuclearHazard 4.4.0 renamed the user from `NuclearHazard` to `nuclear`, so the old installer failed with "install location not found". It now locates RotorHazard from its service configuration instead of hardcoded paths, stages and validates files before replacing anything (a failed download leaves the working plugin intact), keeps the last three versions under `.vrxc_elrs-backup/`, confirms the plugin loaded after restarting, and supports `--dry-run`, `--ref=` and `--dir=`.

### ⚠️ No firmware reflash needed

Plugin-only release. Keep the ELRS Netpack (XIAO / Wrover) on v2.4.

### Installation & Update

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yanazoo/vrxc_elrs/master/tools/install.sh)
```

To install this exact version:

```bash

```

### Verified

- On real hardware (NuclearHazard 4.4.0, Raspberry Pi 5): installer run, and position, race clock, lap time and best lap all shown together
- A full-race simulation under two goggle models (persistent canvas, and display-only-what-was-written): the old code reproduces the reported symptom, the new code shows every element under both
- All 40 defaults checked automatically against the requested settings table
