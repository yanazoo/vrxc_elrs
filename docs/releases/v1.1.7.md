<a name="日本語"></a>

## 日本語

### 修正：レース終了後にクロック・ラップタイム・FINISHED! が消えないことがある

v1.1.6 では、行を消すときに空白で上書きします（全消去は使いません）。ところが、レースクロックが止まった後は画面を描き直す処理がありません。そのため、消去の書き込みが ESP-NOW 上で 1 つ落ちると、表示がそのまま残っていました。

- LAND NOW! の後のレースクロック
- 5 秒後に消えるはずのラップタイム
- 10 秒後に消えるはずの FINISHED! / 順位

**修正**として、画面の内容が変わる表示を 0.2 秒間隔で再送するようにしました。

| 表示の種類 | 送信回数 |
|---|---|
| 表示を出す（ラップタイム・順位・GO! など） | 合計 3 回 |
| 表示を消す（行を空にする・全消去） | 合計 5 回 |
| レースクロックの秒送り | 1 回（毎秒送るため再送なし） |

1 回落ちても次の再送で直るため、**出るべき表示は出て、消えるべき表示は期限どおりに消えます**。

### 推奨：ELRS Netpack v2.6

ESP-NOW ブリッジ（Wrover-E / XIAO ESP32-C3）に [elrs-netpack v2.5](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.5) を書き込んでいる場合は、**[v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6) に更新してください**。v2.5 には、送信が 1 回失敗すると画面更新が丸ごと失われ、レースクロックの秒が飛ぶ・ラップタイムが出ない不具合があります。

### インストール・アップデート

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yanazoo/vrxc_elrs/master/tools/install.sh)
```

このバージョンを指定して入れる場合:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yanazoo/vrxc_elrs/master/tools/install.sh) --ref=v1.1.7
```

### 動作確認

- gevent 上で再送の回数を確認しました（表示 3 回・クロック 1 回・消去 5 回）
- [FPV C5 Lap Timer](https://github.com/yanazoo/FPV-C5-Lap-Timer) の `test/crosscheck_vrxc.py` で、20 % のパケットロスを模擬したレース 100 本（レース停止後のクロック消去を含む）がすべて合格しました。再送をなくすと多数失敗することも確認しています
- 実機（RotorHazard）での確認はこれからです

## English

### Fixed: the clock, lap time or FINISHED! could stay up after the race

v1.1.6 takes a row off by overwriting it with spaces, but once the race clock stops nothing redraws the screen, so a single lost write left the clock after LAND NOW!, an expired lap time or FINISHED! up for good.

Displays that change the screen are now repeated 0.2 s apart: 3 sends in all for something drawn, 5 for something taken off (a row emptied or a full clear); the race clock's own ticks are not repeated. A lost burst is repaired by the next repeat, so elements appear and go on time.

### Recommended: ELRS Netpack v2.6

If the ESP-NOW bridge runs elrs-netpack v2.5, update it to [v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6): v2.5 dropped the rest of a burst after one failed send, losing whole screen updates (clock seconds skipped, lap times missing).

### Installation & Update

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yanazoo/vrxc_elrs/master/tools/install.sh) --ref=v1.1.7
```

### Verified

- Repeat counts checked running under gevent (3 / 1 / 5)
- 100 lossy races (20 % packet loss) in FPV C5 Lap Timer's `test/crosscheck_vrxc.py`, the clock clear after the stop included, all pass; without the repeats most fail
- Not yet checked on real RotorHazard hardware
