## 日本語

### 修正：ラップタイムが時々ゴーグルのOSDに表示されない

ラップタイムは（毎秒再送されるレースクロックと違い）**1回きりの送信**のため、経路のどこかで1回失われるとそのラップは二度と表示されませんでした。本リリースはプラグイン側の送信方法を見直し、失われる窓を大幅に削減します。

**⚠️ [ELRS Netpack v2.4](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.4)（ファームウェア側の修正）と併せての適用を強く推奨します。**

### バグ修正

| 修正内容 | 詳細 |
|---|---|
| **ラップタイムが表示されないことがある** | 1ラップにつき4つの独立したOSDバースト（順位/ラップ数・ラップタイム・ベスト・トータル）を送信しており、それぞれの `SET_SEND_UID` がブリッジ側のESP-NOW再初期化を誘発（1ラップで最大4回）。これを **`SET_SEND_UID` 1回・`DISPLAY` 1回の単一バースト**に統合し、再初期化回数を1/4に削減 |
| **新しいラップタイムが早く消えることがある** | 前のラップの表示クリアタイマーが、後から表示された新しいラップタイムを消してしまうレース条件を修正。パイロットごとの世代トークンで古いクリアを抑制 |
| **表示処理が例外で停止する可能性** | 表示時間などの数値オプションが文字列や未設定の場合に `TypeError` で表示処理が死ぬ可能性を修正（防御的なfloat変換を導入） |

## English

### Fixed: lap times occasionally never appeared on the goggle OSD

Unlike the race clock (re-sent every second), a lap time is transmitted **only once** — if that single transmission is lost anywhere along the path, the lap never shows up. This release reworks how the plugin sends lap OSD updates to drastically reduce the loss window.

**⚠️ Strongly recommended together with [ELRS Netpack v2.4](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.4) (the firmware-side fix).**

### Bug Fixes

| Issue | Fix |
|---|---|
| **Lap time sometimes not displayed** | Each lap used to send 4 separate OSD bursts (position/lap count, lap time, best lap, total time), each with its own `SET_SEND_UID`, which makes the bridge re-initialize ESP-NOW up to 4x per lap. All per-lap updates are now merged into **a single burst with one `SET_SEND_UID` and one `DISPLAY`** |
| **New lap time disappearing early** | Fixed a race condition where the previous lap's delayed row-clear timer wiped a newer lap time off the screen. A per-pilot generation token now suppresses stale clears |
| **Display greenlet could die on bad option values** | Numeric uptime options are now parsed defensively; a string or unset value can no longer raise `TypeError` inside the display path |
